# Source archive

Original filenames and folder copies are retained so historical identities and
sibling imports remain traceable. The parent repository README maps the model
families. `Cartesian/README.md` describes the complete compact half-step bundle.

Do not run historical scripts indiscriminately: some start immediately on import,
use fixed cluster paths, or resume existing output directories. Read the repository
run guide and audit before selecting a case. Sources in legacy directories or with old
names have not been silently changed into modern or validated methods.

Essential scientific/operational comments remain; decorative comments were removed without altering the original Python AST. Docstrings and
string literals are functional data and were retained; some old descriptions
inside them are stale. Use the audit for the settings actually executed.
