# Reduced-height rectangular 3D model

`run3D001.py` is the 600 x 300 x 200 mm model used for the reduced-height results in Section 6.6. The diagnostic patcher and monitored launchers belong to this family. Set their work and production paths before use.

`run3D001_monitored_job_18909391.py` retains one representative monitored source; the duplicate job copies were identical. The large configured time target is not the interval analysed in the thesis.

`rectangular_plume_3d_trial.py` is a separate 800 x 400 x 450 mm trial, not the thesis reference geometry. The later full-height model is kept separately.
