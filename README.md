Source code for the numerical models used in my PhD thesis.

The repository contains the main Cartesian, axisymmetric and rectangular 3D model families implemented in FEniCS, together with the associated post-processing and verification scripts.

Software
The simulations were developed using FEniCS 2019.1.0 and run on a high-performance computing cluster.

Notes
This repository contains the source code used for the numerical work presented in my thesis. Simulation output files and large result datasets are not included.
